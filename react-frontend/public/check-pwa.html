📋 Troubleshooting Steps

If you still see old icons:

  1. Hard Refresh: Press Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
  2. Clear Browser Cache:
    • Chrome: Settings → Privacy → Clear browsing data → Cached images
    • Or press Ctrl + Shift + Delete
  3. Uninstall PWA: If already installed, uninstall the app and reinstall
  4. Check Files: Verify pwa-192x192.png and pwa-512x512.png are in public/ folder
  5. Restart Server: Stop (Ctrl+C) and restart: npm run dev
